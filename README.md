
# BPO QA Analytics Dashboard
 
This project presents an interactive data analytics dashboard built with Python and Streamlit to analyze BPO (Business Process Outsourcing) performance metrics.
 
## Key Features
 
- KPI Monitoring (QA Score, AHT, CSAT, Compliance)
- Interactive filtering by team, campaign, and channel
- Exploratory Data Analysis (EDA) using visualizations
- Trend analysis across time (monthly performance)
 
## Technologies Used
 
- Python (Pandas, NumPy)
- Streamlit
- Matplotlib & Seaborn
 
## Objective
 
The goal of this project is to simulate real-world operational analytics scenarios by analyzing performance data and generating actionable insights to support decision-making.
 
## How to Run
 
```bash
pip install -r requirements.txt
streamlit run bpo_qa_streamlit_dashboard.py
